## Yang Bisa Karsa Bangun

- Dashboard internal dan portal admin
- Tools digitalisasi alur kerja dan proses
- MVP untuk produk tahap awal
- Aplikasi yang terintegrasi dengan API pihak ketiga

## Proses

Pekerjaan aplikasi web sangat mengandalkan tahap Memahami dan Menentukan — memetakan alur kerja yang sebenarnya sebelum satu antarmuka atau kode pun ada, sehingga hasil pembangunan sesuai dengan cara tim benar-benar bekerja.
